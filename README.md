# Statistical mechanics of multi-agent systems

A theoretical research line: can statistical mechanics (Ising/Potts models, partition functions, renormalization group) tell us when adding agents to an LLM multi-agent system helps and when it hurts?

## Status (October 2026)

**Early-stage theory, not a validated result.**

- Completed: literature mapping, partition-function derivation, phase-transition analysis (phases 1–3, 11 of 47 planned steps; see [`.gpd/ROADMAP.md`](.gpd/ROADMAP.md)).
- Not started: simulation, model validation, the predictive framework, the paper.
- No original empirical validation has been completed. Literature comparisons and theoretical interpretations remain preliminary.

## Data policy

Validation will use public datasets and publicly released Content Factory metrics only. No employer or customer data is used.
